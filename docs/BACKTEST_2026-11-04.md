Typical veto: webhook fires on a **15m/1H breakout or PVA**, planner arrives **~20–180+ minutes late**, last already extended or faded, **4H/daily still soft**, **C7 reference = 0** → `no_trade`. That matches phrases like *“LTF stale chase vs soft HTF/daily C7=0”*.

Demo book since start: equity ~91.3k vs 102.5k (−11%), ~31 closed trades, win rate ~23%. Opens are rare *and* the few that fired were not edge-rich.

### Mechanical C7 gates on 2y history

On ~235k instrument-hours (watchlist proxy):

| Gate | Result |
|------|--------|
| C7 signal bars | **6.67%** of bars (Donchian12 + 1h EMA50/200 trend) |
| **Daily-hard filter** (require daily trend = C7 side) | blocks **46.6%** of C7 signals |
| Flat 1h trend bars | 13.6% |

So a planner that waits for **daily + C7 + non-stale LTF** is stacking three rare conditions. The daily-hard proxy alone cuts nearly half the mechanical signals and **hurts OOS** (below).

## 5. Recommended approaches (do not auto-wire yet)

### A — Primary: Pullback / limit retest (best OOS)

**When a wake or C7 prints a breakout, do not market-chase.** Arm a working order:

1. **Trigger:** C7 long/short **or** monitor `breakout_up/down` on 15m/1H with `trend` aligned on that bar.
2. **Arm level:** breakout Donchian level (`hh20`/`ll20`) or 1H EMA20 (whichever is closer to price on the signal bar).
3. **Entry:** limit (or stop-limit) on retest within **±0.4 ATR** of the level, valid **12 hours** (or until 1h trend flips against).
4. **Skip / cancel if:** at arm time `|last − level| / level > 0.5%` already extended the wrong way without touch → leave as watch only (keeps `KILL_ENTRY_SLIP_PCT` / no-chase).
5. **Stop / TP:** same C7 geometry (3×ATR stop, 2R TP, chandelier after +1R). Cap stop 0.6–8%.
6. **Size:** `RISK_PER_TRADE` × soft daily scaler — daily align 1.0×, flat 0.7×, against 0.4×. **Do not hard-block** on daily soft alone.
7. **Risk gate:** keep 2% daily kill, 3-loss pause, 900s stale veto, correlation groups. Prefer `order_type=limit`.

This directly attacks *stale LTF chase*: latency becomes “wait for retest,” not “miss forever.”

### B — Secondary: Regime switch (add after A)

- **Trend regime** (`ATR%/median(ATR%,100) ≥ 1.05` or `|EMA20−EMA50|/ATR ≥ 0.8`): use A (pullback C7).
- **Range regime** (ATR% compressed): mean-revert — fade Donchian extremes with RSI&lt;35 / &gt;65, **0.6× risk**, TP ~1.2R, stop 3×ATR; only when 1h trend flat/weak.

OOS on all-watch was mildly positive; crypto-only OOS was soft — treat as **add-on**, not replacement.

### C — Explicitly avoid

- **Hard daily C7 filter** (current planner habit): −9.9% OOS crypto, fewer trades.
- **Naked MTF momentum / RSI cross**: weak WR (~39%), poor IS.
- **Loosening chase veto or daily kill** to force more market entries: not supported; pullback already raises *useful* participation inside current gates.
- **TradFi as frequency filler**.

## 6. Caveats

1. **Overfit risk:** one IS/OOS cut, shared feature family. Pullback won on both crypto-12 and all-watch OOS, which helps, but still one research pass.
2. **Lookahead:** features use closed bars + merge_asof availability; stop/TP pessimistic (stop first if both hit).
3. **Funding not modelled.** News/event blocks not modelled (live will still pause around NFP/FOMC).
4. **TradFi / OKB / oil history &lt; 2y** — results there are weaker and shorter.
5. **Live ≠ bar bot:** 98 straight `no_trade` wakes are a **planner policy** problem; C7 alone already fires ~6.7% of hours. Fix entry *style* and daily *sizing*, not “more indicators.”
6. Demo PnL (−11%, WR~23%) includes discretionary/legacy trades; not identical to these mechanical paths.
